## 设计说明

### 三个旋钮

这不是把某个现成字体换个名字。从思源宋体出发，动了三处：

1. **字身横向收窄 9%** —— 整个字往中间收，不是把笔画压细
2. **笔画对比重新分配** —— 横笔减薄、竖笔不动，横竖比 2.06 → 2.96
3. **字形改用日文字形写法** —— `直` `者` `骨` `次` 这类字与中文写法不同；日文字形里缺的 8,248 个字，用思源宋体 CN 补齐

### 收窄不等于缩放

直接把整字横向缩 0.9，竖笔会跟着细一成——那是「笔画变细」，不是「字变窄」。

所以做法是：横向压窄之后，**再沿 x 方向把竖笔的厚度补回去**（`dilate_horizontal`）。
补的量按竖笔实测宽度算，收多少补多少。

实测（1000 upem）：

| 项目 | 母本 | 戏墨扁舟体 |
|---|---|---|
| `一` 横笔 | 33 单位 | **23 单位** |
| `十` 竖笔 | 68 单位 | **68 单位** |
| 字面宽（永明朝体書国 五字均值） | 905.8 | **821.7**（−9.3%） |
| `国` 墨迹 | 0.845 × 0.899 em | **0.760 × 0.888 em** |
| 横竖比 | 2.06 | **2.96** |

宽度收进来自字身收窄；高度那 1% 是压细横笔时轮廓边界内移造成的。

### 压细横笔会切断笔画，桥接能救

腐蚀压细时，细横的起笔（三角形鱗的尖端）比两倍腐蚀量还薄，会被整段吃掉——
`着` 的三条横与撇断开、`崇` 的宀顶横与竖断开，在 300px 以上肉眼可见。

解法是把腐蚀量拆成两半用：**腐蚀 7、桥接 2**。

```
E = S ∩ (S 上移 h) ∩ (S 下移 h)        ← 压细
R = E ∪ (母本 ∩ 膨胀(E, r))             ← 桥接（只加不减，不可能凭空断开）
```

净减细严格等于 `h − r`，所以横笔还是 23。实测断笔从 11 字降到 4 字（146 字样本），
剩下的 4 个字（`然` `激` `幽` `游`）单独用更小的 h 重做。

踩过的坑：先试过闭运算（膨胀后再腐蚀），细尖处数值不稳，**反而把笔画切断**
（`说` `集` `流` `次` 各多出 2 个连通域，缝宽 25–46 单位）；也试过 `r ≥ h` 的桥接，
等于把腐蚀量原样补回，`一` 量出来还是 33——白做。

### 字距

转换母本时踩过一个坑：思源宋体的 charstring 从 0 起画，真正的左侧留白记在 `hmtx` 里。
直接转 TTF 会把每个字左移自己的 lsb（`国` 99、`日` 61、`把` 11），字距就会忽宽忽窄。
现在的构建在读取时补回 lsb、写回时按实际轮廓边界记录，成品墨迹落点与母本一致。
